每天十張新桌布，
不會重複。Ten new wallpapers a day.
Never the same twice.

UTUVO Wallpaper 用你自己的 OpenAI API key，每天畫出十張不同主題、光線和構圖的桌布，自動分進 15 個分類、輪播到每一個螢幕；還能把同一個場景做成會跟著時間從早到晚變化的桌布。UTUVO Wallpaper uses your own OpenAI API key to paint ten wallpapers a day — new subjects, light and composition each time — sorts them into 15 categories, rotates them across every display, and turns one scene into a wallpaper that follows the day from dawn to night.

你的 key、你的資料Your key, your data

用你自己的 OpenAI API keyBring your own OpenAI API key

畫圖走 OpenAI Images API（gpt-image-2），費用算在你自己的 OpenAI 帳號。一張圖一次請求；一組日夜場景是一次產生加三次修改。沒有 key 也能看內建的示範圖、用純色和漸層。Pictures come from the OpenAI Images API (gpt-image-2), billed to your own OpenAI account. One picture is one request; a day-and-night scene is one generation plus three edits. Without a key you can still browse the demo pictures and use solid colors and gradients.

key 存在哪裡？Where is the key kept?

存在 Mac 的鑰匙圈，只放在記憶體裡用，不寫進記錄、狀態檔、錯誤訊息或圖片資訊。鑰匙圈鎖住時 App 會停下來，不會改去別處找。In the Mac Keychain, and only held in memory while used. It never goes into logs, status files, error messages or picture metadata. If the Keychain is locked, the app stops instead of looking elsewhere.

會不會一直花錢？Will it keep spending?

每天最多一批十張。網路斷掉時只補缺的，每個主題最多重試三次。純色和漸層完全不呼叫 API。At most one batch of ten a day. If a connection drops it only fills the gaps, with at most three tries per theme. Solid colors and gradients never call the API.

圖放在哪？Where do the pictures go?

~/Library/Application Support/UTUVO Wallpaper，一天約 130 MB（原圖加 6K 版本），不會自動刪。6K 版本是 Core Graphics 重新取樣，不是 AI 放大。~/Library/Application Support/UTUVO Wallpaper, about 130 MB a day (originals plus 6K versions), never deleted automatically. The 6K version is Core Graphics resampling, not AI upscaling.
